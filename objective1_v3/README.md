## Run in Colab

1. Upload `CKINN_Objective1_Colab_STANDARD_v3.ipynb` to Colab. Choose a **CPU** runtime (the original run used CPU; a GPU changes the run identity).
2. In cell 01, keep `RUN_MODE = "STANDARD"` and `OPTION_OVERRIDES = {"broader_rich": True, "site_holdout": True, "alt_zero": True}`.
3. Run cells 00 to 04b. Cell 04b must print `same run: True`. If not, it lists what differs. See section 5 of the review.
4. Set `RUN_STAGE` and run all cells, once per value, in this order: `"EXPLAIN"`, `"SUBGROUPS"`, `"SCREEN"`, `"EXT"`, `"SENSITIVITY"`, `"REPORT"`.
5. After a disconnect, rerun the same `RUN_STAGE`. Finished work is restored from `checkpoints/` on Drive.

Return the files listed in section 10 of the review. Never share `checkpoints/` or `data/`.
